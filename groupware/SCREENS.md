# 화면 설계서 - 사내 그룹웨어 (대시보드 · 출퇴근 · 주간보고 · 연차 · 결재 관리 · 문서 · 회의실 예약)

> 기준 문서: [DESIGN.md](./DESIGN.md) (3. 시연 시나리오, 5. 데이터 모델, 6. API 계약, 7. 화면 구성, 시각 디자인 시스템)

## 1. 대시보드 (`#/home`)

### 팀장 대시보드 와이어프레임 (`role === 'manager'`)
```text
+------------------------------------------------------------------+
| 대시보드 · 2026-11-26 · 박팀장 (개발팀)                          |
+----------------+-------------------+--------------+--------------+
| [달력] 연차대기| [문서] 주간보고대기| [체크] 승인  | [X] 반려     |
| 1건 (#/approvals/leave) | 1건 (#/approvals/weekly) | N건 | N건 |
+----------------+-------------------+--------------+--------------+
| 최근 결재 요청                [ 연차 결재 보기 ] [ 주간보고 결재 보기 ]|
| 신청 직원       | 종류 | 기간/주차 | 일수/시간 | 사유/요약 | 상태 | 처리 |
| 김신입/신청일.. | 연차 | 11/27~28  | 연차 2일  | 개인 사유 | [대기]|[상세]|
+--------------------------------+---------------------------------+
| [오늘 출퇴근]     상세 보기 -> | [잔여 연차]         신청·내역 -> |
| [팀 주간보고 종합] 팀 종합  -> | [오늘 내 회의]     회의실 예약-> |
| [오늘 팀 부재자]   캘린더   -> | [공지사항]  [+공지작성] [전체보기]|
+------------------------------------------------------------------+
```
- **구성원 대시보드**: `오늘 출퇴근` · `잔여 연차` · `내 결재 현황` · `이번 주 주간보고`(엑셀 업로드 링크) · `오늘 내 회의` · `오늘 팀 부재자` · `공지사항`(첨부파일 선형 클립 아이콘) 구성.
- **임원 대시보드**: 주차별 팀 요약 카드(`GET /api/executive/weekly`) + `오늘 내 회의` + `공지사항` 구성.
- **연동 API**: `GET /api/home?userId=`, `GET /api/approvals?approverId=`, `GET /api/approvals/history?approverId=`(팀장), `POST /api/attendance/check-in|check-out`, `GET /api/notices`, `POST /api/notices`(팀장), `GET /api/executive/weekly?executiveId=&weekStart=`(임원)

## 2. 출퇴근 (`#/attendance`) — 구성원 · 팀장 전용

- **연동 API**: `GET /api/home?userId=`, `POST /api/attendance/check-in|check-out`, `GET /api/attendance?userId=&month=YYYY-MM`, `GET /api/attendance/team?managerId=`(팀장)
- **구성·상태**: 오늘 출퇴근 상태·지각(`09:00` 기준) 카드, 팀장 전용 오늘 팀 근태 현황 표, 월별 기록표 및 합계. 임원에게는 메뉴 숨김.

## 3. 주간보고 (`#/weekly`) — 역할별 3가지 화면

### 3-A. 구성원 (`role === 'employee'`) — `.xlsx` 업로드 및 읽기 전용 2단 미리보기
```text
+-------------------------------------------------------------------------------+
| 주간보고 · 김신입 · 개발팀 · 엑셀(.xlsx) 업로드     [< 이전 주] [이번 주] [다음 주 >] |
+-------------------------------------------------------------------------------+
| [업로드] 사내 주간보고 엑셀(.xlsx) 파일을 드래그하거나 클릭하여 업로드하세요     |
|          최대 2MB · 임시저장/반려 상태에서는 새 파일 업로드 시 덮어쓰기 됩니다  |
+-------------------------------------------------------------------------------+
| [!] 파싱 경고 / 반려 의견 (해당 시 노출)                                       |
| (읽기 전용 2단 테이블 + [ 원본 다운로드 ] + [ 제출하기 ] + 지난 주간보고 목록)  |
+-------------------------------------------------------------------------------+
```
- **연동 API**: `POST /api/weekly-reports/upload?userId=&fileName=`, `POST /api/weekly-reports/:id/submit`, `GET /api/weekly-reports/:id/file?viewerId=`, `GET /api/weekly-reports/current?userId=`, `GET /api/weekly-reports?userId=`

### 3-B. 팀장 (`role === 'manager'`) — 팀 종합
- **구성·API**: 주차 이동, 통계 카드, 팀원 제출 현황(모달 내 읽기 전용 2단 양식 + `원본 다운로드` + 제출 건 승인/반려), 프로젝트별 시간 막대, 이슈/요청/개인일정 모음, `#/approvals/weekly` 바로가기, 팀 종합 의견 저장 (`GET /api/weekly-reports/team?viewerId=&weekStart=`, `PUT /api/team-summaries`).

### 3-C. 임원 (`role === 'executive'`) — 팀별 현황 및 드릴다운
- **구성·API**: 주차별 전체 팀 요약 카드 (`GET /api/executive/weekly?executiveId=&weekStart=`), 팀 카드 클릭 시 읽기 전용 팀 종합 화면 및 팀원 보고 열람·원본 다운로드 드릴다운 (`GET /api/weekly-reports/team?viewerId=&team=&weekStart=`).

## 4. 연차 (`#/leave`) — 구성원 · 팀장 전용

- **구성·API**: 잔여/사용/대기/총 부여 카드(`GET /api/users/:id/balance`), 연차·반차 신청 폼(평일 미리보기, `POST /api/leave-requests`), 내 신청 내역 및 대기 건 취소(`GET /api/leave-requests?userId=`, `POST /api/leave-requests/:id/cancel`), 7열 팀 월간 캘린더(`GET /api/leave-calendar?userId=&month=YYYY-MM`). 임원에게는 숨김.

## 5. 결재 관리 (`#/approvals/leave`, `#/approvals/weekly`) — 구성원 · 팀장 전용

### 연차 결재 (`#/approvals/leave`, 기본) & 주간보고 결재 (`#/approvals/weekly`) 분리 와이어프레임
```text
+-------------------------------------------------------------------------------+
| 결재 관리 · 연차 결재                       [ (연차 결재 [1]) | (주간보고 결재 [1]) ] |
+----------------------+----------------------+---------------------------------+
| [달력] 연차 대기 N건 | [체크] 연차 승인 N건 | [X] 연차 반려 N건               |
+----------------------+----------------------+---------------------------------+
| ((결재 대기))  (전체)  (승인)  (반려)                                         |
| 신청 직원 | 연차 유형 | 기간 | 일수 | 사유 | 상태 | 처리 ([상세][승인][반려])  |
+-------------------------------------------------------------------------------+

+-------------------------------------------------------------------------------+
| 결재 관리 · 주간보고 결재                   [ (연차 결재 [1]) | (주간보고 결재 [1]) ] |
+----------------------+----------------------+---------------------------------+
| [문서] 주간보고 대기 N건 | [체크] 승인 N건  | [X] 반려 N건                    |
+----------------------+----------------------+---------------------------------+
| ((결재 대기))  (전체)  (승인)  (반려)                                         |
| 작성자 | 주차 | 금주 총 시간 | 이슈·요청 요약 | 제출일 | 상태 | 처리           |
| 김신입 | 11월 4주차 | 금주 40시간 | 이슈·요청... | 2026.11.26 | 제출됨 | 상세/승인/반려 |
+-------------------------------------------------------------------------------+
  * 주간보고 행 또는 [상세] 클릭 시 2단 표 상세 + [원본 다운로드] 모달 오픈
  * 구성원 로그인 시 동일 2개 탭에서 [내가 올린 연차] / [내가 올린 주간보고] 조회
```
- **연동 API**: 팀장 `GET /api/approvals?approverId=`, `GET /api/approvals/history?approverId=`, `POST /api/leave-requests/:id/(approve|reject)`, `POST /api/weekly-reports/:id/(approve|reject)`, `GET /api/weekly-reports/:id/file?viewerId=`; 구성원 `GET /api/approvals/mine?userId=` (프론트에서 `item.kind`로 분리).

## 6. 문서 (`#/docs`, `#/docs/:id`, `#/docs/new`, `#/docs/:id/edit`) — 전체 공통 (위키)

### 데스크톱 와이어프레임 (Confluence/Jira 스타일)
```text
+-------------------------------------------------------------------------------+
| 문서                                   [ 제목/본문/이슈키 검색... ] [검색] [+ 새 문서] |
+-------------------------------------------------------------------------------+
| [검색 시] 검색 결과 N건: [그룹웨어 프로젝트] 그룹웨어 v1 출시 일정 > 마일스톤 + 발췌 |
+--------------------+----------------------------------------------------------+
| 좌측 페이지 트리    | 문서 / 그룹웨어 프로젝트 / 그룹웨어 v1 출시 일정 [GW] [편집] |
|                    |----------------------------------------------------------|
| [폴더] 그룹웨어..  | 그룹웨어 v1 출시 일정                                     |
|  > 출시 일정 [GW]  | [출시] [마일스톤]       최종 수정 박팀장 · 2026. 11. 26. 09:00 |
| [폴더] 사내 가이드  |                                                          |
|  · 연차·회의실 안내 | > 예시 문서입니다... / ## 마일스톤 / 표(완료/진행 중/예정 배지) |
+--------------------+----------------------------------------------------------+
```
- **마크다운/편집 기능**: HTML 이스케이프 후 안전한 DOM 렌더링(제목 `h1`~`h4` 앵커 ID, 문단, 굵게 `**`, 인라인 코드, 인용 `>`, 목록, 파이프 표, 구분선, `http(s)` 링크). 표 상태어(`완료` 초록·`진행 중` 인디고·`예정` 회색)를 알약 배지로 스타일링. 작성/편집(`#/docs/new`, `#/docs/:id/edit`)은 스페이스 선택/직접 입력, 제목, 라벨, 본문 textarea + 실시간 미리보기 제공.
- **연동 API**: `GET /api/docs`, `GET /api/docs/:id`, `POST /api/docs`, `PUT /api/docs/:id`, `GET /api/docs/search?q=&limit=5`

## 8. 업무 챗봇 (우측 하단 도우미)

- **연동·문서 출처 칩**: `chatbot.js`는 `#user-select` / `localStorage`(`groupware.selectedUserId`)를 공유하며 `window.groupwareRefresh()`로 화면과 `연차 결재`·`주간보고 결재` 배지를 새로고침한다. 문서 질문 응답에 `citations` 배열이 포함되면 말풍선 아래 클릭 가능한 `출처: <제목> > <구간>` 칩을 표시하고 클릭 또는 `navigate`(`route: "docs"`, `docId`) 액션 시 `#/docs/<id>`로 이동해 해당 제목 구간으로 스크롤한다. 임원 계정에서도 `docs` 화면 이동 및 출처 칩을 지원한다.
