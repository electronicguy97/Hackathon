# 화면 설계서 - 사내 그룹웨어 (대시보드 · 출퇴근 · 주간보고 · 연차 · 결재 관리 · 회의실 예약)

> 기준 문서: [DESIGN.md](./DESIGN.md) (3. 시연 시나리오, 5. 데이터 모델, 6. API 계약, 7. 화면 구성, 시각 디자인 시스템)

## 1. 대시보드 (`#/home`)

### 팀장 대시보드 와이어프레임 (`role === 'manager'`)
```text
+------------------------------------------------------------------+
| 대시보드 · 2026-11-26 · 박팀장 (개발팀)                          |
+----------------------+----------------------+--------------------+
| [시계] 결재 대기 2건 | [체크] 승인 완료 N건 | [X] 반려 N건       |
+----------------------+----------------------+--------------------+
| 최근 결재 요청                                       [ 내역 보기 ]|
| 신청 직원       | 종류 | 기간/주차 | 일수/시간 | 사유 | 상태 | 처리 |
| 김신입/신청일.. | 연차 | 11/27~28  | 연차 2일  | 개인 | [대기]|[상세]|
+--------------------------------+---------------------------------+
| [오늘 출퇴근]     상세 보기 -> | [잔여 연차]         신청·내역 -> |
| [팀 주간보고 종합] 팀 종합  -> | [오늘 내 회의]     회의실 예약-> |
| [오늘 팀 부재자]   캘린더   -> | [공지사항]  [+공지작성] [전체보기]|
+------------------------------------------------------------------+
```
- **구성원 대시보드**: `오늘 출퇴근` · `잔여 연차` · `내 결재 현황` · `이번 주 주간보고`(엑셀 업로드 링크) · `오늘 내 회의` · `오늘 팀 부재자` · `공지사항`(첨부파일 선형 클립 아이콘) 구성.
- **임원 대시보드**: 주차별 팀 요약 카드(`GET /api/executive/weekly`) + `오늘 내 회의` + `공지사항` 구성.
- **연동 API**: `GET /api/home?userId=`, `GET /api/approvals?approverId=`, `GET /api/approvals/history?approverId=`(팀장), `POST /api/attendance/check-in|check-out`, `GET /api/notices`, `POST /api/notices`(팀장), `GET /api/executive/weekly?executiveId=&weekStart=`(임원)

## 2. 출퇴근 (`#/attendance`) — 구성원 · 팀장 전용

- **연동 API**: `GET /api/home?userId=`, `POST /api/attendance/check-in|check-out`, `GET /api/attendance?userId=&month=YYYY-MM`, `GET /api/attendance/team?managerId=`(팀장)
- **구성·상태**: 오늘 출퇴근 상태·지각(`09:00` 기준) 카드, 팀장 전용 오늘 팀 근태 현황 표, 월별 기록표 및 합계. 임원에게는 메뉴 숨김.

## 3. 주간보고 (`#/weekly`) — 역할별 3가지 화면

### 3-A. 구성원 (`role === 'employee'`) — `.xlsx` 업로드 및 읽기 전용 2단 미리보기
```text
+-------------------------------------------------------------------------------+
| 주간보고 · 김신입 · 개발팀 · 엑셀(.xlsx) 업로드     [< 이전 주] [이번 주] [다음 주 >] |
+-------------------------------------------------------------------------------+
| [업로드] 사내 주간보고 엑셀(.xlsx) 파일을 드래그하거나 클릭하여 업로드하세요     |
|          최대 2MB · 임시저장/반려 상태에서는 새 파일 업로드 시 덮어쓰기 됩니다  |
|          (업로드 중: 선택 파일명·크기 + 진행 표시줄)                          |
+-------------------------------------------------------------------------------+
| [!] 파싱 경고 (있을 때 노출) / [!] 반려 의견 (반려 상태일 때 노출)            |
+--------+-----------------------------------+----------------------------------+
| 항목   | 11월 4주차(11/23 ~ 11/27) 금주    | 12월 1주차(11/30 ~ 12/04) 차주   |
| (읽기 전용 2단 테이블 — 웹 직접 편집 없음; 지난 주간보고 목록에서 양식 보기·다운로드) |
+--------+-----------------------------------+----------------------------------+
|                                           [ 원본 다운로드 ]   [ 제출하기 ]    |
+-------------------------------------------------------------------------------+
```
- **연동 API**:
  - `POST /api/weekly-reports/upload?userId=&fileName=` (`Content-Type: application/octet-stream`, `<=2MB`) → `{ report, warnings }` (`draft` 저장, 기존 `draft`/`rejected` 덮어쓰기; `submitted`/`approved`면 `409` 인라인 오류)
  - `POST /api/weekly-reports/:id/submit` (`{ userId }`) → `submitted` 전환
  - `GET /api/weekly-reports/:id/file?viewerId=` → 업로드된 `.xlsx` 원본 다운로드
  - `GET /api/weekly-reports/current?userId=`, `GET /api/weekly-reports?userId=`

### 3-B. 팀장 (`role === 'manager'`) — 팀 종합
- **구성·API**: 주차 이동, 통계 카드, 팀원 제출 현황(모달 내 읽기 전용 2단 양식 + `원본 다운로드` + 제출 건 승인/반려), 프로젝트별 시간 막대, 이슈/요청/개인일정 모음, `#/approvals` 이동(`결재 관리 바로가기 →`), 팀 종합 의견 저장 (`GET /api/weekly-reports/team?viewerId=&weekStart=`, `PUT /api/team-summaries`).

### 3-C. 임원 (`role === 'executive'`) — 팀별 현황 및 드릴다운
- **구성·API**: 주차별 전체 팀 요약 카드 (`GET /api/executive/weekly?executiveId=&weekStart=`), 팀 카드 클릭 시 읽기 전용 팀 종합 화면 및 팀원 보고 열람·원본 다운로드 드릴다운 (`GET /api/weekly-reports/team?viewerId=&team=&weekStart=`).

## 4. 연차 (`#/leave`) — 구성원 · 팀장 전용

- **구성·API**: 잔여/사용/대기/총 부여 카드(`GET /api/users/:id/balance`), 연차·반차 신청 폼(평일 미리보기, `POST /api/leave-requests`), 내 신청 내역 및 대기 건 취소(`GET /api/leave-requests?userId=`, `POST /api/leave-requests/:id/cancel`), 7열 팀 월간 캘린더(`GET /api/leave-calendar?userId=&month=YYYY-MM`). 임원에게는 숨김.

---

## 5. 결재 관리 (`#/approvals`) — 구성원 · 팀장 전용

### 팀장 와이어프레임 (`role === 'manager'`)
```text
+-------------------------------------------------------------------------------+
| 결재 관리 · 개발팀 연차 · 주간보고 결재 요청을 한눈에 관리합니다.               |
+----------------------+----------------------+---------------------------------+
| [시계] 결재 대기 N건 | [체크] 승인 N건      | [X] 반려 N건                    |
+----------------------+----------------------+---------------------------------+
| ((결재 대기 N))  (전체 N)  (승인 N)  (반려 N)                                 |
+------------------+------+------------+------------+---------------+------+----+
| 신청 직원        | 종류 | 기간/주차  | 일수/시간  | 사유/요약     | 상태 | 처리|
| 김신입           | 연차 | 2026-11-27 | 연차 · 2일 | 개인 사유     |[대기]|[상세][승인][반려]|
| 신청일 2026.11.20|      |            |            |               |      |    |
| 김신입           |주간보고| 11월 4주차 | 금주 40h   | 차주 40h·xlsx |[대기]|[상세][승인][반려]|
+------------------+------+------------+------------+---------------+------+----+
  * [상세]: 주간보고는 모달 내 읽기 전용 2단 엑셀 양식 + [원본 다운로드] + 승인/반려 표시
  * [반려]: 반려 의견 입력 모달 호출(주간보고 반려 시 의견 필수)
```
- **연동 API**: 팀장 `GET /api/approvals?approverId=`, `GET /api/approvals/history?approverId=`, `POST /api/leave-requests/:id/(approve|reject)`, `POST /api/weekly-reports/:id/(approve|reject)`, `GET /api/weekly-reports/:id/file?viewerId=`; 구성원 `GET /api/approvals/mine?userId=` (필터 탭 + 동일 통합 테이블 + 상세/재업로드 안내). 임원에게는 숨김.

## 6. 회의실 예약 (`#/rooms`) — 전체 공통 (마곡 사무실)

- **구성·API**: `GET /api/rooms`, `GET /api/room-reservations?date=YYYY-MM-DD`, `POST /api/room-reservations`, `GET /api/room-reservations/mine?userId=`, `POST /api/room-reservations/:id/cancel`. 데스크톱 24칸 시간표 / 모바일 목록, 빈 칸 클릭 예약 모달, 409 중복 예약 오류 인라인 표시.

## 7. 업무 챗봇 (우측 하단 도우미)

- **연동·동기화**: `chatbot.js`는 `#user-select` / `localStorage`(`groupware.selectedUserId`)를 공유하며 `window.groupwareRefresh()`로 `대시보드`·`결재 관리`·`주간보고` 등 현재 화면과 `#nav-approvals-badge`를 즉시 새로고침한다. `chatbot.css`는 `style.css`의 `--primary`(`#4F46E5`) 등 CSS 변수를 그대로 상속한다.
