# 화면 설계서 - 사내 그룹웨어 (홈 · 출퇴근 · 주간보고 · 연차 · 승인)

> 기준 문서: [DESIGN.md](./DESIGN.md) (3. 시연 시나리오, 6. API 계약, 7. 화면 구성)
> 바닐라 HTML/CSS/JS 기반 SPA, 해시 라우팅(`#/home`, `#/attendance`, `#/weekly`, `#/leave`, `#/approvals`) 지원.

## 0. 공통 레이아웃 (Global Layout) 및 권한 정책

### 데스크톱 와이어프레임
```text
+-------------------------------------------------------------------------------------+
| [GW 홈] 사내 그룹웨어                           [김신입 (개발팀) v]  [사원 / 팀장]  |
+------------------+------------------------------------------------------------------+
|  목차 (Sidebar)  |  활성 라우트 본문 (#/home | #/attendance | #/weekly | #/leave ...) |
|                  |                                                                  |
|  > 홈            |  [ 전역 오류 배너 (API 실패 시 노출 + 다시 시도) ]               |
|    출퇴근        |                                                                  |
|    주간보고      |  [ 화면별 헤더 / 카드 / 폼 / 표 / 캘린더 ]                       |
|    연차          |                                                                  |
|    승인 [2]*     |                                                                  |
+------------------+------------------------------------------------------------------+
                     * 승인 대기 건수 배지: role === 'manager' 이고 대기 > 0 일 때 표시
```

### 모바일 레이아웃 (`<= 860px`)
```text
+------------------------------------------+
| [GW 홈]     [김신입 (개발팀) v] [사원]   |
+------------------------------------------+
| [홈] [출퇴근] [주간보고] [연차] [승인 2] |  <- 상단 가로 스크롤/줄바꿈 메뉴
+------------------------------------------+
|               본문 (1열 스택)            |
+------------------------------------------+
```

### 공통 요소 및 권한별 노출
| 요소 | 설명 | 연동 API | 권한별 노출 |
|---|---|---|---|
| 홈 버튼 (로고 + `홈`) | 클릭 시 어느 화면에서든 `#/home` 이동 | - | 공통 |
| 사용자 전환 드롭다운 | 선택 변경 시 `localStorage` 저장 후 현재 라우트 재조회 | `GET /api/users` | 공통 |
| 역할 배지 | `employee` → `사원`, `manager` → `팀장` | `GET /api/users` | 공통 |
| 좌측 목차 (모바일 상단 가로 메뉴) | 5개 메뉴 아이콘+라벨, 현재 해시 강조(`aria-current="page"`) | `GET /api/home?userId=` (배지 동기화) | 메뉴 전체 공통 / `승인` 대기 배지는 `manager` 전용 |

## 1. 홈 (`#/home`)

### 와이어프레임
```text
+------------------------------------------------------------------+
| 홈 대시보드 · 2026-11-26 (김신입 · 개발팀)                       |
+-------------------------------+----------------------------------+
| [오늘 출퇴근]   상세 보기 ->  | [잔여 연차]         신청·내역 -> |
| 상태: [근무 중]  [정상 출근]  | 잔여: 15일                       |
| 출근: 08:55 / 퇴근: -         | 대기 2일 · 사용 0일 / 총 15일    |
| [ 퇴근하기 ]                  |                                  |
+-------------------------------+----------------------------------+
| [결재 현황]     결재함 가기-> | [이번 주 주간보고]    작성하기 ->  |
| 팀장: 결재 대기 N건           | 2026-11-23 주                    |
| 사원: 내 진행 중 결재 N건     | 상태: [미작성 / 제출됨 / 반려됨] |
+-------------------------------+----------------------------------+
| [오늘 팀 부재자]     캘린더-> | [공지사항]         [+ 공지 작성]*|
| - 이분석 [연차]               | - [고정] 워크샵 해커톤 안내      |
| (없으면 "부재 중인 팀원 없음")| - 연말 연차 사용 권장            |
+-------------------------------+----------------------------------+
                                  * [+ 공지 작성] 버튼은 role === 'manager' 전용
```

### 구성 요소 및 연동 API
| 구성 요소 | 설명 | 연동 API |
|---|---|---|
| 대시보드 집계 로딩 | 오늘 출퇴근, 연차, 주간보고, 결재 건수, 팀 부재자, 상위 공지 3건 | `GET /api/home?userId=` |
| 출근 / 퇴근 버튼 | `none` → `출근하기`, `working` → `퇴근하기`, `done` → 완료 표시 | `POST /api/attendance/check-in`, `POST /api/attendance/check-out` |
| 카드 바로가기 링크 | 각 카드 클릭/링크로 `#/attendance`, `#/leave`, `#/approvals`, `#/weekly` 이동 | - |
| 공지사항 상세 모달 | 공지 클릭 시 전체 본문·작성자 조회 | `GET /api/notices` |
| 공지 작성 모달 (팀장) | 제목·본문·상단 고정 입력 후 등록 | `POST /api/notices` |

### 상태 및 권한
- **로딩**: 대시보드 스켈레톤/로딩 문구 표시, 출퇴근 버튼 요청 중 비활성화
- **빈 상태**: 부재자 없음(`오늘 부재 중인 팀원이 없습니다.`), 공지 없음(`등록된 공지사항이 없습니다.`)
- **오류**: 4xx(중복 출근 409, 공지 권한 403 등) 발생 시 해당 카드/모달 내 `error` 메시지 표시
- **성공**: 출퇴근/공지 등록 후 즉시 `/api/home` 및 네비게이션 배지 재조회
- **권한**: 결재 카드 문구는 팀장(`approvalPendingCount` 강조)과 사원(`myPendingCount` 표시)으로 구분; `+ 공지 작성`은 `role === 'manager'`만 노출

## 2. 출퇴근 (`#/attendance`)

### 와이어프레임
```text
+------------------------------------------------------------------+
| 출퇴근 관리                                                      |
+------------------------------------------------------------------+
| 오늘 근태 (2026-11-26) | 상태: [근무 중] [지각]                  |
| 출근: 09:05   퇴근: -                                [ 퇴근하기 ]|
+------------------------------------------------------------------+
| [팀장 전용] 오늘 팀 근태 현황                                    |
| +--------+----------+------+------+------+                      |
| | 이름   | 상태     | 출근 | 퇴근 | 지각 |                      |
| | 김신입 | 근무 중  | 09:05| -    | 지각 |                      |
| | 이분석 | 휴가중   | -    | -    | -    |                      |
| +--------+----------+------+------+------+                      |
+------------------------------------------------------------------+
| 월별 근태 기록   [ 2026-11 v ]   출근 18일 | 총 148시간 20분 | 지각 1회 |
| +------------+------+------+----------+------+                   |
| | 근무일     | 출근 | 퇴근 | 근무시간 | 지각 |                   |
| | 2026-11-02 | 08:52| 18:10| 9시간 18분| 정상 |                   |
| +------------+------+------+----------+------+                   |
+------------------------------------------------------------------+
```

### 구성 요소 및 연동 API
| 구성 요소 | 설명 | 연동 API |
|---|---|---|
| 오늘 기록 + 출퇴근 버튼 | 오늘 상태, 출근/퇴근 시각, `09:00` 초과 시 `지각` 배지 | `GET /api/home?userId=`, `POST /api/attendance/check-in`, `/check-out` |
| 오늘 팀 근태 표 (팀장) | 팀원별 오늘 출퇴근·지각·휴가(`onLeave`) 현황 | `GET /api/attendance/team?managerId=` |
| 월 선택기 + 합계 카드 | `YYYY-MM` 선택 시 월별 기록·출근 일수·총 근무 분·지각 횟수 조회 | `GET /api/attendance?userId=&month=YYYY-MM` |

### 상태 및 권한
- **로딩**: 월 변경·출퇴근 처리 중 로딩 상태 표시 및 버튼 중복 클릭 차단
- **빈 상태**: 해당 월 기록 없음(`선택한 월의 출퇴근 기록이 없습니다.`)
- **오류**: 이미 출근/퇴근(409), 권한 없음(403) 등 API `error` 메시지 노출
- **성공**: 출퇴근 처리 후 오늘 상태 + 월간 기록표 + 팀 근태 표 + 배지 동시 갱신
- **권한**: `오늘 팀 근태 현황` 섹션 및 `/api/attendance/team` 호출은 `role === 'manager'` 전용

## 3. 주간보고 (`#/weekly`)

### 와이어프레임
```text
+------------------------------------------------------------------+
| 주간보고                                                         |
+------------------------------------------------------------------+
| 이번 주 보고 (2026-11-23 주)          상태: [반려됨]             |
| [!] 반려 의견 (박팀장): 이슈 항목 보완                           |
|                                                                  |
| 업무 항목                                [ + 항목 추가 ]         |
| +----------------+--------+--------------------------+---------+ |
| | 프로젝트       | 시간(h)| 업무 내용                | [삭제]  | |
| | [그룹웨어]     | [ 16 ] | [화면 설계 및 구현]      | [삭제]  | |
| +----------------+--------+--------------------------+---------+ |
|                                        총 투입 시간: 16시간      |
| 차주 계획: [                                                   ] |
| 이슈/건의: [                                                   ] |
|                                      [ 임시저장 ]   [ 제출하기 ] |
+------------------------------------------------------------------+
| 지난 주간보고 목록                                               |
| > 2026-11-16 주 | 총 40시간 | [승인됨] | 확인했습니다  [상세보기]|
+------------------------------------------------------------------+
```

### 구성 요소 및 연동 API
| 구성 요소 | 설명 | 연동 API |
|---|---|---|
| 이번 주 보고 조회 | 주차(`weekStart`), 기존 항목·계획·이슈·반려 사유 바인딩 | `GET /api/weekly-reports/current?userId=` |
| 업무 항목 동적 행 | `+ 항목 추가` / `삭제` 버튼, `hours` 실시간 합계(`totalHours`) 계산 | - |
| 임시저장 / 제출 버튼 | `submit: false`(`draft`) 또는 `submit: true`(`submitted`) 전송 | `PUT /api/weekly-reports` |
| 지난 보고 목록 | 과거 주차 목록(최신순), 클릭 시 항목·계획·이슈·의견 아코디언 상세 | `GET /api/weekly-reports?userId=` |

### 상태 및 권한
- **로딩**: 현재 보고·지난 보고 조회 중 폼 잠금/로딩 안내, 저장/제출 요청 중 버튼 비활성화
- **빈 상태**: 이번 주 미작성 시 빈 항목 1행 제공; 지난 보고 없음(`아직 작성된 지난 주간보고가 없습니다.`)
- **오류**: 제출 항목 0건/0시간(400), 이미 제출·승인된 보고 수정 시도(409) 시 API `error` 폼 내 표시
- **성공**: 저장/제출 후 이번 주 보고, 지난 목록, 네비게이션 배지 갱신 (`submitted`/`approved` 상태에서는 수정 폼 읽기 전용 잠금)
- **권한**: 모든 사용자(`employee`, `manager`) 본인 주간보고 작성 가능

## 4. 연차 (`#/leave`)

### 와이어프레임
```text
+------------------------------------------------------------------+
| 연차 관리                                                        |
+------------------------------------------------------------------+
| [잔여: 15일]  [사용: 0일]  [대기: 2일]  [총 부여: 15일]          |
+----------------------------+-------------------------------------+
| 연차 신청                  | 내 신청 내역                총 N건  |
| 유형: [연차/오전/오후 v]   | 기간      | 유형 |일수|상태|의견|관리|
| 시작일 / 종료일 (반차 고정)| 12.01~02  | 연차 | 2일|대기| -  |[취소]|
| 예상 차감: 2일 (평일 계산) | 11.10     | 반차 |0.5 |승인|확인| -  |
| 사유 + [신청하기]          |                                     |
+----------------------------+-------------------------------------+
| 팀 월간 연차 캘린더               [ 2026-12 v ]  (승인 / 대기)   |
|  일   |  월   |  화 (1)       |  수 (2)       |  목   | 금 | 토  |
|       |       | [김신입(대기)]| [김신입(대기)]|       |    |     |
+------------------------------------------------------------------+
```

### 구성 요소 및 연동 API
| 구성 요소 | 설명 | 연동 API |
|---|---|---|
| 잔여 연차 카드 4종 | 잔여·사용·대기·총 부여 일수 + 추가 신청 가능 일수 | `GET /api/users/:id/balance` |
| 연차 신청 폼 | 유형(`annual`/`half_am`/`half_pm`), 반차 시 종료일 동기화·잠금, 평일 미리보기 | `POST /api/leave-requests` |
| 내 신청 내역 표 | 상태 배지(`대기`/`승인`/`반려`/`취소`), `pending` 행에만 `취소` 버튼 | `GET /api/leave-requests?userId=`, `POST /api/leave-requests/:id/cancel` |
| 팀 월간 캘린더 | 월별 7열 달력 그리드에 팀 내 `pending`·`approved` 휴가 배지 표시 | `GET /api/leave-calendar?userId=&month=YYYY-MM` |

### 상태 및 권한
- **로딩**: 내역·캘린더 로딩 표시, 신청/취소 요청 중 버튼 비활성화
- **빈 상태**: 신청 내역 없음(`신청한 연차 내역이 없습니다.`), 해당 월 팀 휴가 없음(빈 달력 + 안내)
- **오류**: 잔여 부족(400), 주말만 선택(400), 취소 불가 상태(403/409) 시 API `error` 표시
- **성공**: 신청/취소 후 잔여 카드·신청 내역·팀 캘린더·네비게이션 배지 일괄 갱신
- **권한**: 모든 사용자가 신청·취소·같은 팀 월간 캘린더 조회 가능

## 5. 승인 (`#/approvals`)

### 와이어프레임
```text
+------------------------------------------------------------------+
| 승인 관리 (팀장: [결재 대기 (2)] [처리 완료] / 사원: 내가 올린 결재)|
+------------------------------------------------------------------+
| [카드 1] [연차] 김신입 · 연차 2일 (2026-12-01 ~ 12-02)   [상세▾] |
|   (클릭 시 상세 확장: 유형, 기간, 일수, 사유, 신청일시)          |
|   결재 의견: [                       ]        [ 반려 ]  [ 승인 ] |
+------------------------------------------------------------------+
| [카드 2] [주간보고] 김신입 · 주간보고 2026-11-23 주 (40시간)[상세▾]|
|   (클릭 시 상세 확장: 업무 항목 표, 차주 계획, 이슈, 총 시간)    |
|   결재 의견: [ 이슈 항목 보완        ]        [ 반려 ]  [ 승인 ] |
+------------------------------------------------------------------+
```

### 구성 요소 및 연동 API
| 구성 요소 | 설명 | 연동 API |
|---|---|---|
| 팀장 - 결재 대기 탭 | 같은 팀 `pending` 연차·주간보고 목록(오래된 순) | `GET /api/approvals?approverId=` |
| 팀장 - 처리 완료 탭 | 내가 처리한 `approved`·`rejected` 목록(처리일 최신순) | `GET /api/approvals/history?approverId=` |
| 사원 - 내가 올린 결재 | 본인이 올린 연차(`cancelled` 제외)·주간보고(`draft` 제외) 현황 | `GET /api/approvals/mine?userId=` |
| 상세 보기 + 결재 액션 | 항목 클릭 시 전체 `detail` 펼침; `kind`에 따라 승인/반려 분기 호출 | `POST /api/leave-requests/:id/approve\|reject`, `POST /api/weekly-reports/:id/approve\|reject` |

### 상태 및 권한
- **로딩**: 목록 조회 중 로딩 표시, 승인/반려 요청 중 해당 카드 버튼 비활성화
- **빈 상태**: 대기 건 없음(`대기 중인 결재 요청이 없습니다.`), 처리 완료/내 결재 없음 안내
- **오류**: 주간보고 반려 시 의견 누락(400), 권한 없음(403), 이미 처리됨(409) 시 API `error` 표시
- **성공**: 승인/반려 후 대기·완료 목록 및 좌측 `승인` 배지 건수 즉시 갱신
- **권한**: `role === 'manager'`는 `결재 대기` / `처리 완료` 탭과 승인·반려 버튼 노출; `role === 'employee'`는 `내가 올린 결재` 읽기 전용 목록만 노출

## 6. 시연 시나리오 화면 흐름 (DESIGN.md 3장)

```text
[1. 김신입 접속 (#/home)]
  상단 사용자: 김신입 (사원) | 좌측 목차 '승인' 배지 없음
  홈 '오늘 출퇴근' 카드에서 [출근하기] 클릭 → POST /api/attendance/check-in
  → 출근 시각과 지각 여부([정상 출근] 또는 [지각]) 즉시 표시
        │
        ▼ (좌측 목차 '연차' 클릭 → #/leave)
[2. 연차 신청 - 김신입 (#/leave → #/home)]
  평일 2일 + 사유 입력 후 [신청하기] → POST /api/leave-requests (201)
  상단 '홈' 버튼으로 #/home 복귀 → 잔여 연차 카드에 '대기 2일' 반영 확인
        │
        ▼ (좌측 목차 '주간보고' 클릭 → #/weekly)
[3. 주간보고 제출 - 김신입 (#/weekly)]
  이번 주 업무 항목(프로젝트·시간·내용), 차주 계획, 이슈 작성 → [제출하기]
  → PUT /api/weekly-reports (submit: true, status: 'submitted')
        │
        ▼ (상단 사용자 전환: 김신입 → 박팀장)
[4. 결재 처리 - 박팀장 (#/home → #/approvals)]
  홈 결재 카드 및 좌측 목차 '승인 [2]' 배지 확인 → #/approvals 이동
  연차 건 [승인] → POST /api/leave-requests/:id/approve (200)
  주간보고 건 의견("이슈 항목 보완") 입력 후 [반려] → POST /api/weekly-reports/:id/reject (200)
  → 대기 목록에서 2건 모두 사라지고 '승인' 배지 제거, '처리 완료' 탭으로 이동
        │
        ▼ (상단 사용자 전환: 박팀장 → 김신입)
[5. 결과 확인 및 재제출 - 김신입 (#/approvals → #/weekly)]
  '내가 올린 결재'에서 연차 [승인], 주간보고 [반려] 및 의견("이슈 항목 보완") 확인
  #/weekly 이동 → 상단 반려 의견 배너 확인 후 이슈 보완 → [제출하기] 재전송
        │
        ▼ (상단 '홈' 버튼 클릭 → #/home)
[6. 홈 복귀 최종 확인 (#/home)]
  어느 화면에서든 상단 '홈' 버튼으로 #/home 즉시 복귀
  잔여 연차 13일(사용 2일 반영), 오늘 팀 부재자, 공지사항 3건 확인
```
